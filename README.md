# CodeNotes – Tech & Programming Blog

A three-page static website made for the Web Development course at ELTE.

**Live demo:** https://tanilhamdi.github.io/codenotes/

## Pages

- **Home** (`index.html`) – latest blog posts about Python, Git and CSS Grid, useful sources and tags
- **Projects** (`gallery.html`) – six of my GitHub projects in a responsive gallery
- **Contact** (`contact.html`) – programming language comparison table, coding guide video with transcript, newsletter and contact form

## Features

- Responsive layout (phone, tablet, desktop)
- High-contrast, large-font version and text size buttons on every page
- Print style sheet
- Valid HTML5 and CSS (W3C validator, jigsaw)

Built with plain HTML, CSS and JavaScript – no frameworks.

The video on the contact page is “How To Learn A New Programming Language” by
[ThePrimeagen](https://www.youtube.com/watch?v=E8cM12jRH7k).
