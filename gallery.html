My Projects

Learning to code means building things. These are six of my favourite open-source projects, from small Linux command-line tools to full-stack web apps. Each card has a short description, the technologies used and a link to the source code. The pictures are illustrations of what each program does – select one to see it in full size.

All my code is public on my GitHub profile: tanilhamdi on GitHub.

wpontime

A lightweight wallpaper switcher for Linux that changes the desktop background according to the time of day. Time periods and images are set in a config file; an install script compiles it and adds a global wpontime command that can run from cron or a systemd timer.

Built with: Java, Shell, feh

  • wpontime on GitHub

easyMove

A small command-line tool that moves a file or folder into the current directory by name from a list of saved folders. It shows a numbered menu for duplicates, falls back to fzf search, and --latest grabs the most recently downloaded file.

Built with: C++17, standard library only

  • easyMove on GitHub

Beggtho? Chat & Dashboard

A full-stack chat and dashboard app with registration and login, JWT sessions in HttpOnly cookies, bcrypt password hashing, protected routes and a chat room that refreshes every five seconds.

Built with: React (Vite), Node.js, Express, MongoDB

  • beggtho on GitHub

HQM – Hospital Queue Management

A hospital queue system: staff register patients with automatic queue numbers and mark them as done, while a TV display mode shows the waiting room which patient is being served.

Built with: C# / ASP.NET Core Minimal API (.NET 9), React 19, Vite

  • HQM-System on GitHub

Land Analysis Tool

A desktop GUI for analysing Turkish real-estate data from Excel files: district counts, land classification, status distribution and area totals. The interface is in Turkish – for example „EXCEL DOSYASI SEÇ” means “select Excel file”. A Windows executable is available.

Built with: Python, Tkinter, Pandas

  • land-analysis-tool on GitHub

transferIt

File transfer on a local network – just pick a port number: no IP addresses, accounts or cloud. A serve mode shows a QR code so phones can download the files in a browser.

Built with: C# (.NET 10), Shell

  • transferIt on GitHub
